Backtest reference · v6

248 overlapping 24-month windows, 2004–2026, per $1,000 of collateral, priced on the parity-measured VIX curve at STRESS = 1.0. This is what live results get judged against, not a forecast. On the raw calm curve (STRESS = 0) the same run means +$396, a −$42 tenth percentile and 15% losing windows.
